# 주의울림 v12 관리자 분리 업데이트

## 변경사항
- 관리자 **말씀 관리**와 **성경공부 관리**를 별도 카드로 분리
- 지난 말씀 선택 → 수정 / 삭제
- 성경공부는 연결할 말씀을 선택 → 등록 / 수정 / 삭제
- 말씀 삭제 시 같은 주차의 성경공부, 말씀쓰기 출석, 성경공부 제출 기록 삭제
- 기도제목은 말씀 삭제 시 주차 연결만 해제하고 내용 보존
- 학생 제출 기록을 **매주 일요일(주일) 날짜별로 묶어서** 표시
- 말씀쓰기 출석 / 성경공부 제출 / 기도제목 / 감사기도 / 익명글을 개별 삭제 가능
- 현재 주일 제출 건수 요약 표시

## 적용 순서
1. Supabase SQL Editor에서 `admin_separated_records_v12.sql` 전체 실행
2. GitHub에서 `index.html`, `app.js`, `styles.css`, `sw.js` 교체
3. GitHub Pages 배포 완료 후 Ctrl+F5
4. 설치형 PWA에서 이전 화면이 남으면 Service Worker Unregister 후 다시 접속

## 참고
관리자가 감사기도 DB 기록을 삭제해도 학생 기기에 이미 저장된 로컬 달력 기록은 자동으로 지워지지 않을 수 있습니다.
