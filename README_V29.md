# 주의울림 V29

이번 버전은 세 가지 기능을 함께 보강합니다.

1. **말씀따라쓰기 연습모드**
   - weekly_contents.week_start 기준 +6일인 해당 주일 오전 10:30(Asia/Seoul) 전에는 말씀을 자유롭게 따라 쓸 수 있습니다.
   - 정확히 완성해도 출석/완료 기록은 서버에 저장되지 않고 `연습 완료`로만 안내합니다.
   - 오전 10:30 이후에는 같은 화면이 자동으로 `출석등록 가능` 모드로 전환됩니다.
   - Supabase RLS와 출석 RPC 내부에도 같은 시간 제한을 적용해 프론트엔드 우회 저장을 막습니다.

2. **감사기도 관리자 삭제 ↔ 학생 챌린지 동기화**
   - 관리자가 감사기도 기록을 삭제하면 학생 감사기도 탭의 연속일수·달력·최근 기록에서도 삭제가 반영됩니다.
   - 같은 브라우저의 학생/관리자 탭은 BroadcastChannel/storage 신호로 즉시 갱신합니다.
   - 다른 기기는 감사기도 탭이 열려 있는 동안 약 15초마다 서버와 동기화합니다.
   - 감사기도 본문은 편집 토큰이 일치하는 본인 기기에만 반환됩니다.

3. **성경공부 답변 10자 이상**
   - 각 질문의 답변을 각각 10자 이상 작성해야 제출 버튼이 활성화됩니다.
   - 답변별 글자 수가 표시됩니다.
   - Supabase 정책과 CHECK 제약에서도 신규 답변의 10자 최소 규칙을 적용합니다.

## 적용 순서
1. Supabase SQL Editor에서 `feature_rules_v29.sql` 전체 실행
2. 마지막 진단 결과가 모두 `true`인지 확인
3. GitHub에 `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.json` 교체
4. GitHub Pages 배포 후 Ctrl+F5
