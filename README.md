# 주의울림 V27 · 감사기도 챌린지 확장

## 변경사항
- 학생 화면 최상단에 현재 감사기도 챌린지를 이어가는 학생과 연속일 표시
- 감사기도 10자 이상 작성 시에만 저장 가능
- 현재 기기에 저장된 감사기도 기록 수정 가능
- 관리자에 `🔥 감사기도` 탭 추가
- 관리자에서 학생별 현재 연속 / 최고 연속 / 누적 일수 확인
- 관리자에서 감사기도 내용을 주일별로 확인하고 개별 삭제
- 공개 챌린지 현황에는 감사기도 본문을 노출하지 않음

## 적용 순서
1. Supabase SQL Editor에서 `gratitude_challenge_v27.sql` 전체 실행
2. GitHub에 `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.json` 교체
3. GitHub Pages 배포 후 Ctrl+F5

## 수정 기능 보안
학생 로그인 계정이 따로 없는 현재 앱 구조에서 다른 학생의 기록을 이름만 바꿔 수정하지 못하도록, 기록 작성 기기에 저장되는 편집 토큰을 사용합니다. 따라서 감사기도 수정은 원칙적으로 작성했던 기기에서 가능합니다.
