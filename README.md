# 주의울림 감사기도 달력 챌린지 업데이트

## 이번 업데이트
- `감사기도` 탭을 달력형 챌린지로 확장
- 감사기도를 기록한 날짜를 월간 달력에 표시
  - 🔥 현재 이어지고 있는 연속 기록
  - ✅ 과거 완료 기록
- 이전 달 / 다음 달 이동 가능
- 월별 감사기도 기록일수 표시
- 7일 연속 달성 시 `🏅 7일 감사습관` 배지 획득
- 30일 연속 달성 시 `🏆 30일 감사습관` 배지 획득
- 배지 미달성 시 현재 연속일수 기준 진행률 표시
- 배지 달성 순간 완료 메시지에 축하 문구 표시
- 기존 현재 연속 / 최고 연속 / 오늘 기록 여부 / 최근 기록 유지
- 감사기도 원문은 계속 Supabase에 저장되며 학생끼리는 공개되지 않음
- PWA 캐시를 `v3-gratitude-calendar`로 올려 새 화면 반영
- 기존 `app.js`에 있던 감사기도 제출 부분의 중복 날짜 변수 오류도 함께 수정

## 적용 순서
1. 기존에 `gratitude_prayers_setup.sql`을 이미 실행했다면 SQL을 다시 실행할 필요가 없습니다.
2. GitHub `youth-worship-app` 저장소에서 아래 파일을 교체합니다.
   - `index.html`
   - `app.js`
   - `styles.css`
   - `sw.js`
3. `manifest.json`과 아이콘 파일은 기존 그대로 사용해도 됩니다.
4. GitHub Pages 배포 후 `Ctrl + F5`로 새로고침합니다.
5. 설치형 PWA가 예전 화면을 보이면 사이트 데이터 삭제 또는 Service Worker 해제 후 다시 엽니다.

## 데이터 저장 방식
감사기도 원문은 Supabase `gratitude_prayers`에 저장됩니다. 학생 화면의 달력·연속일수·배지는 개인정보를 다른 학생에게 노출하지 않기 위해 해당 기기의 localStorage 기록을 기준으로 계산합니다. 따라서 같은 기기에서는 계속 유지되지만 브라우저 데이터를 삭제하거나 다른 기기로 바꾸면 학생 화면의 달력/배지 표시가 초기화될 수 있습니다. Supabase에 저장된 감사기도 원문은 유지됩니다.
