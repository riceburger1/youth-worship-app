# 주의울림 관리자 말씀·성경공부 편집 V10

## 변경사항
- 말씀 저장을 성경공부 저장과 분리해 말씀만 먼저 등록 가능
- 지난 말씀/성경공부 선택 후 수정 가능
- 성경공부만 삭제 가능
- 학생 제출 기록이 없는 주차는 말씀+성경공부 전체 삭제 가능
- 공지사항 최신 1개 상단 노출 및 기존 공지 수정 기능 유지
- 감사기도 달력/배지 기능 유지

## 적용 순서
1. Supabase SQL Editor에서 `admin_weekly_editor_v7.sql` 전체 실행
2. GitHub에서 `index.html`, `app.js`, `styles.css`, `sw.js` 교체
3. 배포 후 Ctrl+F5 또는 Service Worker 재등록
4. 관리자 화면에서 `관리자 말씀·성경공부 편집 v10 준비 완료.` 확인
