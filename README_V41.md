# 주의울림 V41 · 학생 찬양 관리자

## 핵심 기능
- 기존 전체 관리자는 모든 관리자 기능 유지
- 학생 찬양 관리자는 `🎵 찬양 관리`만 사용
- 학생이 관리자 로그인 화면에서 직접 찬양 관리자 계정을 만들 수 있음
- 전체 관리자가 `찬양 관리 → 학생 찬양 관리자`에서 이메일로 승인/해제
- 찬양 관리자는 YouTube 검색, 주일별 곡 추가, 순서 변경, 삭제 가능
- YouTube API 키는 전체 관리자만 등록/수정 가능
- RLS에서도 말씀/성경공부/기도/감사/익명/새친구/통계/행사 데이터 접근 차단

## 적용 순서
1. Supabase SQL Editor에서 `feature_update_v41.sql` 전체 실행
2. GitHub의 `index.html`, `app.js`, `styles.css`, `sw.js` 교체
3. Ctrl+F5 새로고침
4. 학생: 관리자 화면 → `학생 찬양 관리자 계정 만들기` → 이메일/비밀번호로 가입
5. 전체 관리자: 관리자 로그인 → `🎵 찬양 관리` → 학생 이메일 입력 → `찬양 관리자 승인`
6. 학생: 같은 관리자 화면에서 로그인 → 찬양 관리 화면만 표시

## 참고
Supabase 프로젝트의 이메일 가입 정책에 따라 가입 후 이메일 인증이 필요할 수 있습니다.
