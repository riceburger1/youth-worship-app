# 주의울림 V18 — 행사·이벤트 달력 기간 선택

## 변경사항
- 행사 시간 입력 제거
- 시작일 / 종료일 기간 선택
- 예: 2026-09-10 ~ 2026-09-12
- 기간에 포함되는 모든 날짜에 행사 표시
- 관리자 날짜 클릭 시 해당 날짜가 포함된 행사 수정/삭제 가능
- 기존 단일 날짜 행사는 SQL 실행 시 시작일=종료일로 자동 변환

## 적용 순서
1. Supabase SQL Editor에서 `event_period_v18.sql` 전체 실행
2. GitHub에서 `index.html`, `app.js`, `styles.css`, `sw.js` 교체
3. GitHub Pages 배포 후 Ctrl+F5
4. 관리자 → 행사 달력에서 시작일/종료일로 테스트

## DB 구조
기존 `event_date` 컬럼을 시작일로 사용하고 `end_date`를 추가합니다.
기존 `start_time`, `end_time` 컬럼은 호환성 때문에 삭제하지 않지만 V18에서는 사용하지 않습니다.
