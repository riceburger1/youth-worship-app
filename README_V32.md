# 주의울림 V32

## 변경사항
- 감사기도 기록 시 다른 기기의 기존 기록 때문에 발생하던 42501 충돌을 오류 대신 안전한 `이미 등록됨` 상태로 처리합니다.
- 학생에게 공개되는 감사기도 연속 챌린지는 TOP 3만 표시합니다.
- 오늘/내일 날씨를 상단에 표시하고, 날씨 카드를 누르면 7일 주간예보를 펼칩니다.
- 기본 날씨는 부산 기준이며 `내 위치` 버튼을 누르면 브라우저 위치 권한을 사용해 현재 위치 예보로 바꿉니다.
- 관리자 감사기도 전체 결과와 삭제 기능은 그대로 유지합니다.

## 적용 순서
1. Supabase SQL Editor에서 `feature_update_v32.sql` 전체 실행
2. 마지막 진단 결과가 모두 true인지 확인
3. GitHub의 `index.html`, `app.js`, `styles.css`, `sw.js` 교체
4. 배포 후 Ctrl+F5
