# 주의울림 V17 - 관리자 탭형 작업공간

## 변경사항
- 관리자 화면을 학생 화면처럼 항목별 탭 방식으로 변경
- 말씀 관리 / 성경공부 / 공지사항 / 기도제목 / 학생 제출 / 행사 달력 6개 탭
- 선택한 관리 항목만 표시해 긴 스크롤 제거
- 각 탭 클릭 시 해당 데이터만 새로 불러와 관리자 화면 로딩 부담 감소
- 기존 등록·수정·삭제 기능 유지
- 모바일 3열/2열 탭 자동 배치
- 마지막으로 사용한 관리자 탭을 같은 브라우저 탭에서 기억
