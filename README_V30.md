# 주의울림 V30

## 적용 순서
1. Supabase SQL Editor에서 `feature_update_v30.sql` 전체 실행
2. 마지막 진단 결과의 주요 값이 모두 `true`인지 확인
3. GitHub에 `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.json` 교체
4. GitHub Pages 배포 후 Ctrl+F5

## V30 주요 변경
- V30 이후 새로 작성하거나 수정한 감사기도 본문을 학년/구분·이름과 함께 전체 공개 (기존 비공개 기록은 자동 공개하지 않음)
- 감사기도 삭제는 관리자만 가능, 작성 기기에서는 기존처럼 수정 가능
- 내 정보 학년/구분에 `선생님` 추가
- 말씀쓰기 출석 인정시간을 해당 주일 10:30 이상 ~ 13:00 미만(KST)으로 제한
- 그 외 시간은 따라쓰기 연습만 가능하고 출석 저장 안 됨
- 새친구 탭 추가
  - 공개: 학년, 이름, 학교
  - 관리자 전용: 연락처, 인도자, 기타정보
- 관리자에 새친구 관리 탭 추가, 전체 정보 확인 및 삭제 가능
