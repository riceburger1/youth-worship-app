# 주의울림 V31

## 변경 내용

1. 성경공부 작성·제출 시간 제한
   - 해당 주일 오전 10:30 이상 ~ 오후 1:00 미만(KST)에만 답변 작성 및 제출 가능
   - 시간 전/후에는 답안 입력칸과 제출 버튼 비활성화
   - 각 답변 10자 이상 규칙 유지
   - Supabase RLS에서도 같은 시간대를 검사해 우회 저장 방지

2. 감사기도 오늘 공개
   - 감사기도 탭의 기본 공개 영역은 오늘 작성된 공개 감사기도만 표시
   - 학년/구분, 이름, 감사기도 내용 공개

3. 감사기도 날짜별 보기
   - 나의 감사 달력에서 과거/오늘 날짜를 클릭 가능
   - 선택한 날짜에 공개된 다른 학생/선생님의 감사기도를 함께 확인
   - 미래 날짜는 클릭 불가

## 적용 순서

1. Supabase SQL Editor에서 `feature_update_v31.sql` 전체 실행
2. 마지막 진단 SELECT의 항목이 모두 true인지 확인
3. GitHub에서 `index.html`, `app.js`, `styles.css`, `sw.js` 교체
4. Ctrl + F5로 강력 새로고침

기존 V30 데이터는 삭제하지 않습니다.
