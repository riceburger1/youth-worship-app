# 주의울림 V46

## 변경사항
- 말씀쓰기의 주일 선택을 드롭다운에서 달력 선택 방식으로 변경
- 성경공부의 주일 선택을 드롭다운에서 달력 선택 방식으로 변경
- 각 달력은 `달력 열기 / 달력 닫기` 가능
- 말씀이/성경공부가 등록된 주일만 클릭 가능
- 선택 후 달력은 자동으로 닫힘
- 학생이 말씀쓰기/성경공부 탭에 들어갈 때마다 서버에서 최신 내용을 다시 확인
- 기본 화면은 항상 가장 최신 주일의 등록 내용을 표시
- 지난 주일 조회 기능 유지
- 지난 주일은 조회 전용, 현재 출석/성경공부 제출 제한시간 규칙 유지

Supabase SQL 변경은 없습니다.
