# 주의울림 V16 - 관리자 행사 날짜 클릭 편집

## 변경사항
- 관리자 행사 달력에서 날짜를 클릭하면 해당 날짜의 행사 목록이 즉시 표시됩니다.
- 일정이 1개인 날짜는 클릭 즉시 편집창에 자동으로 불러옵니다.
- 일정이 여러 개인 날짜는 각 행사 카드에서 `수정` 또는 `삭제`를 바로 누를 수 있습니다.
- 행사 카드를 눌러도 편집창에 불러옵니다.
- 같은 날짜에 새 행사를 추가하는 `＋ 새 행사` 버튼을 제공합니다.
- 모바일에서는 수정/삭제 버튼이 2열 전체폭으로 표시되어 누르기 쉽습니다.
- 기존 행사 등록/수정/삭제, 학생 달력 공개/비공개 기능은 유지합니다.

## 적용
Supabase SQL 추가 실행은 필요 없습니다.
GitHub에서 `index.html`, `app.js`, `styles.css`, `sw.js`를 교체하고 강력 새로고침하세요.
